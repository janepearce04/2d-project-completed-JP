The first change was the cosmetic updates, I duplicated several trees scenes and simply changed the sprite. One thing to add just a little more depth to the game is generating foliage in places the players hasn't been before.
Additionally the gun and bullet sprite was something I made in piskel and simply replaced the original texture.

The second change I made was adding a score system to keep track of how many slimes have been beaten. I was also considering adding different enemy types and having them have different attacks as well as different point values but I ran out of time to implement this.

The third change is the traps I've added, mostly player driven script like the slimes, but it's generated in the same way as the trees are on the map, for this one I used the free pixel art dungeon objects and just had it so that traps trigger once and then become inactive, I though it would be interesting if you really had to watch where you were going.

Regardless, I was intending to code in a restart button as well but that never ended up working for some reason, I've ran out of time as well.

Hope this was interesting, thanks to all contributers.
